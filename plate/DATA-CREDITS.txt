InstaSlice Studio star data
===========================

InstaSlice Studio's own plate solver (plate/custom) uses three compact star
indexes. They contain star directions and four-star geometric patterns (the
bright and mid-depth indexes hold only the star lists from which the patterns
are generated when they are opened). They do not contain photographs, image metadata or user data.

wide.isp.gz     Bright stars (magnitude 7.8 or brighter) from the whole sky.
mid.isp.gz      Stars to G = 9.65 (341,627) from the whole sky: the same Gaia
                DR3 and Hipparcos 2 data at a fainter limit.
deep.isq.gz     Gaia DR3 stars (G <= 14) in selected deep-sky fields in both
                hemispheres. plate/custom/CREDITS.txt lists the covered fields.

The bright-star table combines Gaia DR3 with the Hipparcos 2 new reduction.
It was obtained as a public measurement table from the catalogue page named
below. The solver software that project distributes is not used by this app.
Catalogue positions are moved to epoch J2000 using their proper motions.
